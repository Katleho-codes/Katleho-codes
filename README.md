## Selected projects

### SlipStream: digital payslips for South African employers
[slipstream.lsquared.org.za](https://slipstream.lsquared.org.za)

Employees at small businesses often can't produce a verifiable payslip when applying for credit. SlipStream fixes that.

- SARS-compliant PDF payslips generated with Puppeteer
- HMAC-SHA256 signed QR codes, so anyone can verify a payslip without logging in
- Audit log for payslips issued, staff changes and sign-in attempts, written fire-and-forget so a logging failure never breaks a request
- PayFast webhook integration for subscription billing
- Multi-stage Alpine Docker build, network-isolated Compose setup, GitHub Actions CI/CD, Vitest tests

`TypeScript` `Node.js` `Express` `Next.js` `Prisma` `PostgreSQL` `Better Auth` `Docker`

### Deliva: e-commerce for local shops
[deliva.lsquared.org.za](https://deliva.lsquared.org.za)

Storefronts, real-time ordering and shop management for local shops and their customers.

- Real-time cart sync and order tracking with Socket.IO and Redis
- Geolocation-based nearby store discovery
- Email/password and Google OAuth, cookie sessions, role-protected dashboards
- PayFast checkout and Redis-backed rate limiting
- Full stack in Docker Compose, backend covered by Vitest and Supertest

`TypeScript` `React` `Next.js` `Express` `PostgreSQL` `Redis` `Socket.IO` `Tailwind`

### Banking-domain REST API
A REST API that implements double-entry ledger accounting, built to understand how core banking systems actually hold together.
